EXACT REVERSIBILITY / A PREDICTION, THEN AN EXPERIMENT

Chaos can scramble. Must it forget?

A rounded kick can still be exactly reversible—if it moves whole cells without merging them.

Both coordinates wrap modulo 8. Here p increases down the screen. Colours and numbers follow original cell identities.

Why no cells are lost

Kick: each column shifts cyclically by the same amount for every cell in it. Drift: each row shifts cyclically by its momentum. Each shift is a bijection; their composition is a permutation. Undo drift first, then undo kick.

Fixed toy kick table: [0, 1, 2, 1, 0, −1, −2, −1]. This 8×8 model teaches the mechanism; it is not the byte kernel.

Concise narration / N

Predict what happens when we scramble a picture and reverse the rule. A floating-point map carries tiny rounding errors. Chaotic trajectories amplify those errors, so reversing the algebra does not necessarily recover the original state. Now look at the small grid. Every kick is a cyclic column shift; every drift is a cyclic row shift. No two cells collide. Select a cell, follow it forward, and undo the shifts in reverse order. The kick was rounded once to a fixed integer table, but the state updates lose no information. The 256×256 model does the same arithmetic modulo 256. Scramble, then run back. We count every misplaced identity; zero in the exact lattice count means return of all integer coordinates in this browser run. That experiment is distinct from the formal proof of the machine kernel. Reversibility does not mean a faithful simulation of every real system: the lattice has changed the model to preserve information.

The exact-byte proof boundary

92 bytes of AArch64 code, under stated preconditions.

The repository’s HOL Light source binds 23 instruction words from build/lattice_echo.o and proves the forward and backward coordinate maps under its memory and ABI preconditions. It also proves the algebraic round trip. See the exact source revision.

This page runs a JavaScript port. Native comparison tests provide empirical agreement for tested states. The proof does not cover this UI, the animation loop, floating-point comparison, the 8×8 toy, browser execution or the rendered pixels. No new proof replay is claimed by this presentation.
