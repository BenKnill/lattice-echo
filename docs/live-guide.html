REHEARSAL / 3–4 MINUTES

Watch one cell come home.

  1. Predict. Select a numbered cell. Ask where it will land. Read its original and current coordinates below the grid.
  2. Kick. Each column shifts by a fixed whole number of cells. Wrapping at the edge loses nothing.
  3. Drift. Each row now shifts by its current momentum. We still have 64 identities in 64 distinct cells.
  4. Undo in reverse order. Undo drift, then undo kick. The final grid returns exactly. The fixed integer kick table is part of the rule.
  5. Scale up. Scramble all 65,536 identities, then Run back. Watch the exact-coordinate count reach zero. The floating-point counter measures wrong display bins, not bitwise equality.

The one sentence to land

Rounding a fixed rule does not have to discard state information: a permutation has an inverse. This changes the numerical model; it does not prove that every real system is reversible on a computer.

Controls

Left/Right: toy half-steps. S: scramble. B: reverse. Space: pause. R: reset both demonstrations. N: narration. F: fullscreen where supported. Keyboard shortcuts leave sliders and normal Space/Enter button activation alone.

Pause stops the current run. Run back reverses however many steps have completed. Scramble adds the selected number of new forward steps. Reset restores both integer and floating-point initial arrays.

What the proof says

LATTICE_FWD_SUBROUTINE_CORRECT and LATTICE_BWD_SUBROUTINE_CORRECT concern the pinned AArch64 instruction bytes and their memory/ABI contract. LATTICE_BWD_FWD, LATTICE_FWD_BWD and LATTICE_ECHO_ROUND_TRIP establish the algebraic inverses.

The browser runs JavaScript. This UI, its calling loop, toy model, float comparison and rendered pixels are outside the machine-code proof. This edition does not claim a new HOL replay or native-kernel benchmark.

Repeatable checks

From the repository root run node tests/live-models.mjs and node tests/live-controls.mjs. The first exhausts all 65,536 cells across eight kick tables and five rotation angles. The second exercises the real controller in a minimal DOM harness. These are regression checks, not visual browser QA.
